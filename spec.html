02. Typography

Display

Playfair Display Italic Black. Used exclusively for high-level branding and section headers to provide an "Editorial/Architectural" feel.

Main Interface

Inter. The workhorse. Bold for headings, medium for actions. Negative letter spacing (-0.02em) on headings for a tighter, premium feel.

technical_data.01

JetBrains Mono. Used for metadata, counters, timestamps, and status badges. Reinforces the "mapping" and "system" nature of the app.

03. Spacing & Geometry

Standard Padding (p-4 to p-6)

Consistent internal padding for cards and sections. Use p-4 for compact UI and p-8 for layout density.

Soft Geometry (rounded-3xl)

Main containers use rounded-3xl or rounded-[2rem] for a modern mobile feel. Inner components use rounded-xl.

Technical Elevation

Shadows should be large, blurred, and colored based on the surface. Avoid generic gray shadows. Use shadow-primary/20.
